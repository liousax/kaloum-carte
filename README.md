# Rues de Kaloum — plan d'adressage (prototype)

Carte interactive du projet d'adressage de Kaloum (Conakry) :
noms de rues proposés, numéros de maisons, codes postaux par quartier (88001, 88002, 88003),
quadrillage, itinéraires, et projet de tramway T1.

**Carte en ligne :** https://liousax.github.io/kaloum-carte/

⚠️ Les noms de rues sont des **propositions** soumises aux autorités : ils ne sont pas officiels.

- `index.html` : la carte (s'ouvre dans n'importe quel navigateur, ordinateur ou téléphone)
- `referentiel-kaloum.json` : noms, codes et numérotation figés le 17/10/2026
- `rues-kaloum.geojson` : les 117 rues, pour les logiciels de cartographie (QGIS…)
